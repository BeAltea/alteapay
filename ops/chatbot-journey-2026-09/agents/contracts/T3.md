## Escopo (§6/T3 + Apêndice B/C + E3/E9)
1. **Exportador de planilha** no formato Voxuy Enterprise: colunas **exatas** `Nome`, `Telefone`, `Email` + coluna extra **`link_negociacao`** (URL `/c/{token}`) — **e nada mais** (E9: sem CPF/valor/dívida). `Nome`=1º nome; `Telefone`=`+55DDD9XXXXXXXX` (internacional, sem separadores, reusar `toE164Mobile`); `Email` vazio no canal WhatsApp. Gerar `.xlsx` **e** `.csv`.
   - Download só `super_admin`; registra `journey_events` `sheet.exported` (contagem + hash do arquivo, **sem PII**); aviso na UI de que o arquivo é dado pessoal.
   - Ao exportar: mensagens da onda → `dispatched`, `channel='whatsapp_sheet'`, `provider_status_source='none'` (Voxuy passa a ser responsável pela entrega; não temos confirmação).
2. **Adapter de API `voxuy_api` (desligado):** mantém o contrato de `PROMPT_VOXUY_2026-09-17.md`; se o Enterprise confirmar endpoint diferente, **só este arquivo muda**. Nenhuma credencial versionada.
3. **Callback `POST /api/webhooks/whatsapp/voxuy`:** captura pura — grava tudo em `whatsapp_provider_events`, dedupe, **nunca 500**. Contrato do provedor é DESCONHECIDO → documentar "a confirmar".
4. **Especificação da template** (`docs/VOXUY_TEMPLATE_SPEC.md`): categoria **Utilidade**, sem valor/menção a dívida, **não iniciar nem terminar com variável** (regra Meta), link em variável/botão de URL. Rascunho no Apêndice C do prompt — validar com `vn-comunicacao` antes de submeter à Meta.

## Critérios de pronto
- Planilha byte-a-byte no formato aceito; `vt-security` confirma **zero PII além das 4 colunas**.
- Callback resiliente (fuzz de payload → nunca 500); dedupe idempotente.
- Sem credencial em arquivo versionado; `SHEET_EXPORT_ENABLED` respeitado.
